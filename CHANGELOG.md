# Change Log

All notable changes to the "Papyrus Scene Graph" extension will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-11-06

### Added
- Syntax highlighting for Papyrus Scene Graph (`.psg`) files.
- TextMate grammar rules for scene graph nodes, attributes, materials, vectors, and numbers.
- Language configuration supporting single-line (`#`) comment toggling and bracket matching (`{}`, `()`, `[]`).
- High-resolution motion-blurred wheel extension icon.

### Changed
- Promoted initial `0.0.1` development build to production `1.0.0` release for VS Code Marketplace launch.
- Renamed project identifier to `papyrus-scene-graph` for standard extension packaging.

## [0.0.1] - 2024-08-26

### Added
- Initial project scaffolding and prototype syntax highlighting definitions.

# Payrus Scene Graph Syntax

This extensions adds syntax highlighting for Papyrus Scene Graph (PSG) files to Microsoft's Visual Studio Code.

## Features

Adds syntax highlighting features to Visual Studio Code for Papyrus Scene Graph files to help NR2003 modders read the script better.

## Requirements

Visual Studio Code v1.92.2 or newer.
